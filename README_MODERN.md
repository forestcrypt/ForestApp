# ForestApp - Современный интерфейс

Приложение для учёта лесных насаждений с современным интерфейсом на KivyMD.

## 🚀 Установка зависимостей

```bash
pip install -r requirements.txt
```

## ▶️ Запуск приложения

### Современный интерфейс (KivyMD):
```bash
python main_modern.py
```

### Классический интерфейс (Kivy):
```bash
python main.py
```

## 📱 Сборка для Android

### Требования:
- Ubuntu/Linux или WSL на Windows
- Buildozer установлен: `pip install buildozer`

### Шаги сборки:

1. Инициализация buildozer:
```bash
buildozer init
```

2. Сборка APK:
```bash
buildozer -v android debug
```

3. Готовый APK будет в папке `bin/`

## 🎨 Особенности современного интерфейса

- **Material Design** компоненты
- **Иконки** Material Icons
- **Тёмная/светлая тема** с переключением

- **Современные анимации** и переходы

## 🔧 Решение проблем

### Ошибка импорта KivyMD:
```bash
pip install kivymd==1.2.0
```

### Ошибка шрифтов:
Убедитесь, что папка `fonts/` существует и содержит файлы:
- Roboto-Medium.ttf
- Roboto-Bold.ttf

### Ошибка базы данных:
База данных `forest_data.db` создаётся автоматически при первом запуске.
