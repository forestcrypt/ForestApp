# Исправление диаметра по породам в проекте ухода

## Проблема

При печати проекта ухода **не прописывался средний диаметр по породам** (исходный и проектируемый).

### Причина

В функции `save_to_json()` модуля `molodniki_extended.py` **не сохранялись итоговые данные** (`total_data`) в JSON файл. 

Функция `fill_our_template.py` загружала данные из JSON:
```python
self.breeds_data = self.total_data.get('breeds', [])
```

Но `total_data` отсутствовал в JSON, поэтому `breeds_data` был пустым и диаметры не заполнялись.

## Решение

Добавлено сохранение `total_data` в JSON файл:

### Изменения в `molodniki_extended.py`

Функция `save_to_json()` (строка 5372):

```python
def save_to_json(self, instance=None):
    """Сохранение данных в JSON формате"""
    # ✅ ПОЛУЧАЕМ итоговые данные (total_data) из меню Итого
    total_data = self.get_total_data_from_db()
    
    data = {
        'page_data': self.page_data,
        'section': self.current_section,
        'quarter': self.current_quarter,
        'plot': self.current_plot,
        'forestry': self.current_forestry,
        'radius': self.current_radius,
        'project_data': self.project_data,
        'total_data': total_data,  # ✅ ДОБАВЛЕНО: итоговые данные с породами
        'export_date': datetime.datetime.now().isoformat()
    }
    # ... сохранение файла
```

## Заполнение в проекте

В `fill_our_template.py` (строки 481-482):

```python
row.cells[5].text = self.format_number(diameter)  # ИСХОДНЫЙ диаметр
row.cells[6].text = self.format_number(project_values['diameter'])  # ПРОЕКТНЫЙ диаметр
```

Где:
- `diameter = breed.get('diameter', 0)` - загружается из JSON
- `project_values['diameter']` - рассчитывается с учётом интенсивности рубки

### Расчёт проектного диаметра

Функция `calculate_project_values()` (строка 246):

```python
def calculate_project_values(self, breed, intensity):
    diameter = breed.get('diameter', 0)
    
    # Коэффициент увеличения (зависит от интенсивности)
    growth_factor = 1 + (intensity / 100) * 0.3  # +30% при 100% интенсивности
    
    project_diameter = diameter * growth_factor if diameter > 0 else 0
    
    return {
        'age': age,
        'height': project_height,
        'diameter': project_diameter,
        'density': None
    }
```

**Логика:** После рубки остаются лучшие деревья, поэтому средний диаметр увеличивается.

## Пример заполнения

### Исходные данные:
- Сосна: d=4.0 см, h=2.5м, интенсивность=30%

### Заполняется в таблице:
| Порода | Диаметр исх | Диаметр проект |
|--------|-------------|----------------|
| Сосна  | 4.0         | 4.36           |

Расчёт: `4.0 * (1 + 30/100 * 0.3) = 4.0 * 1.09 = 4.36 см`

## Примечания

- Диаметр сохраняется только если был введён пользователем
- Проектный диаметр рассчитывается с коэффициентом роста
- Если диаметр = 0, поле остаётся пустым (форматирование через `format_number()`)
