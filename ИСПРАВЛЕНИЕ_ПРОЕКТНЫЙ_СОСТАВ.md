# Исправление проектного состава по породам

## Проблема

**Проектный состав** в таблице проекта ухода рассчитывался неправильно - просто копировался из исходного состава, вместо того чтобы браться из **предмета ухода**.

### Было (НЕПРАВИЛЬНО):

```python
composition_isx = self.calculate_breed_composition(breed_name, density, total_density)
composition_project = composition_isx  # ❌ Просто копируется!
```

**Результат:** Если исходный состав был "5С3Б2Ос", то проектный тоже был "5С3Б2Ос", независимо от предмета ухода.

## Решение

### Принцип работы

**Проектный состав должен браться из предмета ухода!**

Пример:
- **Исходный состав:** 5С3Б2Ос
- **Предмет ухода:** 3С2Б
- **Проектный состав:** 3С (для сосны), 2Б (для берёзы), пусто (для осины)

### Новые функции

#### 1. `parse_care_subject_by_breeds()` (строка 245)

Парсит предмет ухода и возвращает словарь {порода: коэффициент состава}:

```python
def parse_care_subject_by_breeds(self, care_text):
    """
    Парсит предмет ухода и возвращает словарь {порода: коэффициент состава}
    Примеры: "3С2Б" → {'Сосна': 3, 'Берёза': 2}
    """
    # Парсит "3С2Б" или "3С 2Б"
    matches = re.findall(r'(\d+(?:\.\d+)?)([А-ЯA-Z][а-яa-z]*)', care_text)
    
    for coeff_str, breed_str in matches:
        coeff = int(float(coeff_str))  # Коэффициент состава (1-10)
        breed_code = breed_str[0].upper()
        breed_name = BREED_DATABASE.get(breed_code, None)
        
        if breed_name:
            result[breed_name] = coeff
    
    return result
```

#### 2. `calculate_project_composition()` (строка 283)

Рассчитывает проектный состав для конкретной породы:

```python
def calculate_project_composition(self, breed_name, care_density_by_breed):
    """
    Рассчитывает проектный состав породы из предмета ухода
    Возвращает: строку вида "3С" или "2Б"
    """
    # Ищем коэффициент для этой породы из предмета ухода
    project_coeff = None
    
    for care_breed, care_value in care_density_by_breed.items():
        if care_breed in breed_name or breed_name.startswith(care_breed):
            project_coeff = care_value
            break
    
    if project_coeff is not None:
        breed_code = get_breed_code(breed_name)
        return f"{int(project_coeff)}{breed_code}"
    
    return ''  # Нет данных в предмете ухода
```

### Применение в заполнении

|--------|------------|---------------|
| Сосна  | 5С         | **3С** (из предмета ухода) |
| Берёза | 3Б         | **2Б** (из предмета ухода) |
| Осина  | 2Ос        | **2Ос** (оставлен исходный, т.к. нет в предмете ухода) |

## Логика определения породы

Функция ищет совпадения по:
1. **Точному вхождению:** "Сосна" в "Сосна обыкновенная"
2. **Первому слову:** "Сосна" == "сосна" (из "Сосна обыкновенная")
3. **Коду породы:** "С" → "Сосна"

## Проверка

1. Откройте проект ухода
2. Найдите таблицу "Таксационные показатели по породам"
3. Столбец "Состав проект" должен соответствовать предмету ухода

### Пример предмета ухода:

- **"3С2Б"** → Сосна: 3С, Берёза: 2Б, остальные: пусто
- **"4С"** → Сосна: 4С, остальные: пусто
- **"2С1Б1Ос"** → Сосна: 2С, Берёза: 1Б, Осина: 1Ос

## Примечания

- Если порода не указана в предмете ухода, оставляется исходный состав
- Коэффициенты состава всегда целые числа (1-10)
- Сумма коэффициентов в предмете ухода должна быть = 10
